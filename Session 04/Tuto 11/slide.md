Synthèse de ma veille technologique

- Définition : La modularité en PHP consiste à diviser le code en plusieurs fichiers et fonctions réutilisables pour rendre une application mieux organisée et plus facile à maintenir.

- Problème résolu pour le projet : Éviter de répéter le même code dans plusieurs pages du blog, réduire les erreurs et faciliter les modifications.

- Mes 3 mots-clés : Inclusion (require_once) — Fonctions réutilisables — Principe DRY (Don't Repeat Yourself).
