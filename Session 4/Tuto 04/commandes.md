Exercice - Commandes PHP

1. Vérifier l'installation de PHP

php -v
Cette commande permet de vérifier que PHP est correctement installé et d'afficher sa version.

2. Démarrer le serveur local

php -S localhost:8000
Cette commande permet de démarrer le serveur web local de PHP sur le port 8000.

3. Accéder au serveur

Ouvrir cette adresse dans le navigateur :
http://localhost:8000

4. Arrêter le serveur

Ctrl + C
